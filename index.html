Falta configurar o Firebase

O app está pronto, mas o arquivo firebase-config.js ainda tem as chaves de exemplo. Para ativar o armazenamento na nuvem:

  1. Crie um projeto em console.firebase.google.com.
  2. Ative o Firestore Database (modo produção ou teste).
  3. Em "Configurações do projeto → Seus apps", crie um app da Web e copie o objeto firebaseConfig.
  4. Cole esses valores em firebase-config.js, substituindo os campos de exemplo.
  5. Recarregue esta página.
